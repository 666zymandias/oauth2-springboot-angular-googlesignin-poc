# Política de Seguridad

## Versiones Soportadas

Actualmente, solo se ofrece soporte de seguridad para la última versión desplegada (Release v1.0.0).

## Reporte de Vulnerabilidades

Este proyecto cumple con **ISO 27001 A.12.6.1**. Si encuentras una vulnerabilidad:

1.  No abras una issue pública
2.  Envía un email a `hydfelipe@gmail.com.com` con la información necesaria
3.  El equipo responderá en menos de 48 horas

## Cumplimiento Normativo

Este software ha sido diseñado siguiendo los principios del **RGPD Art. 25**, implementando:
* Autenticación robusta (OAuth2).
* Escaneos de seguridad automatizados (DAST/SAST).
* Gestión segura de dependencias (SBOM).
